# MODARIS GitHub Pages distribution

- Snapshot: MODARIS artist-scenes edition, the fourth build of 2026-11-16, made with `npm run build` from the working tree of `harvey-yang-cargame-portfolio` (its Modaris changes are not committed there, so there is no source commit hash for this build). It replaces the showcase build published earlier the same day (`index-CT0bIQIN.js`).
- What changed in this build: `index.html` (entry script only), two new hashed files in `assets/` (`index-GwPHXd3g.js`, `rapier-THQAc8hH.js`), ten scene files in `modaris/showcase/` and `CREDITS.md`. Everything else is unchanged and retained. Ten scenes made by other artists, each published by its author on Sketchfab under CC BY 4.0, stand as background scenery on nine islands with a plaque naming the work, its author and the licence. `CREDITS.md` lists each scene, its source and what was changed (scaled, placed, relit, textures resized to 1024 px WebP, two viewer sky domes removed). MODARIS is a non-commercial educational project.
- Migration date: 2026-11-07.
- Public entry: `https://gmyoung.github.io/car-game/?edition=world`; the same page also accepts `?edition=tour`.
- This directory contains the published static distribution. No original working-tree changes, private Site metadata, development environment files, keys, test evidence or recordings are included.
- The HTML favicon and preload paths, and the web manifest icon/start paths, were made relative for `/car-game/`. Page metadata now describes MODARIS and its GitHub Pages URL. Game scripts, shaders, models, textures, sounds, mobile controls and historical hashed resources are retained from the published snapshot.
- The compiled multiplayer server start method is empty, matching the source build's disabled server URL. Gameplay does not require a ChatGPT login or application server. Scores and achievements remain browser-local; data on the old Site origin does not automatically transfer to GitHub Pages.
- Runtime asset URLs, decoder paths and model texture references remain relative to this page or their respective resource files. Model libraries retain their licenses and source manifests; see `THIRD_PARTY_NOTICES.md` and `LICENSE.txt`.
- Verification for this migration is limited to saved-file, syntax and static dependency/path checks. No browser, driving or touch functionality was automatically tested.
- Verification for the 2026-11-16 update: the same source was driven on localhost with an input-only test driver (all ten circuits finished and returned to the portal court; nine laps valid) and this production build was loaded once on localhost without console errors. Phones, gamepads and a full Tour were not tested.
- Verification for the island edition: the same source was driven on localhost with an input-only test driver. All ten circuits finished and returned to the portal court; nine laps were valid, and Midnight Rail Loop was not because the driver does not wait for trains. The production build was checked statically (no development harness, no Chinese text). Phones, gamepads, a full Tour and frame rate on weak devices were not tested.
- Verification for the showcase edition: the same source was driven on localhost with an input-only test driver. All ten circuits finished and returned to the portal court; nine laps were valid, and Midnight Rail Loop was not because the driver does not wait for trains. One wide view per island was checked by screenshot. The production build was checked statically (no development harness, no Chinese text). Frame rate with the wide view, phones, gamepads and a full Tour were not tested.
- Verification for the artist-scenes edition: on localhost each added scene was viewed once from the middle camera stretch of its island, except Voxel World, which was not viewed; several were moved afterwards without a second look. No lap tests were run for this build. The production build was checked statically (no development harness, no Chinese text). Frame rate, load time on slow connections and phones were not tested.

To update this copy, start with the intended published static snapshot, retain the original licenses and complete dependent assets, adapt the HTML/manifest paths for `/car-game/`, and publish it through the parent repository's Pages workflow. Do not copy `.openai`, `.git`, environment files, raw recordings or private development records into this public directory.
